# ComicCraft

ComicCraft is an AI-powered comic story creator.

The application takes a story idea and creates:

- A five-panel comic outline
- Detailed narration
- Captions
- Character dialogue
- AI-generated panel images
- A browser-based comic preview
- A downloadable PDF

## Technology

Frontend:

- HTML
- CSS
- JavaScript
- Jinja2

Backend:

- Python
- FastAPI
- Uvicorn

AI:

- Google Gemini
- Hugging Face image generation

PDF:

- FPDF2

Validation:

- Pydantic

Testing:

- Pytest
